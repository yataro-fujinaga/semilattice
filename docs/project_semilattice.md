---
name: Semilattice (sl)
description: ファイルシステムの上に乗る意味的関係レイヤー。AIエージェントの探索コストをゼロにする
type: project
---

Rust製CLIツール。ファイルツリーの上にセミラティス構造の関係レイヤーを構築し、AIエージェントが「探索せずに」必要なファイル群へ到達できるようにする。

**Why:** AIエージェントは毎回tree→open→import辿り→繰り返しで関係構造を復元している。この探索で得た知識を捨てているのがもったいない。

**How to apply:** Jujutsuと同じ設計思想（既存バックエンドはそのまま、操作モデルだけ独自化）。メタデータは `.sl/` に格納。ベクトルDBで意味的検索。AIの作業副産物として関係が自然蓄積される設計。
